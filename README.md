# JS-тест по PA_ses_delo.docx

В проекте 269 вопросов, извлечённых из предоставленного Word-файла.
В исходном документе правильные ответы отмечены знаком `+`; сайт использует именно эти отметки как ключ.

## Запуск

Самый простой вариант — открыть `index.html` в браузере.

Если браузер ограничивает локальные файлы, запустите локальный сервер:

```bash
python -m http.server 8000
```

и откройте `http://localhost:8000`.

## Возможности

- 269 вопросов из исходного документа;
- один или несколько правильных ответов;
- случайная выборка 20 / 50 / 100 / всех вопросов;
- перемешивание вариантов;
- режим «Экзамен» без показа правильных ответов до завершения;
- режим «Тренировка» с немедленной проверкой;
- прогресс;
- процент результата;
- разбор ошибок.

Данные вопросов находятся в `questions.js`, логика — в `app.js`, оформление — в `styles.css`.


## Тесты
Сайт содержит два теста с переключением на стартовом экране:
- Основной тест — СЭС: 269 вопросов.
- Сестринское дело в стоматологии: 525 вопросов.
